# Contributing

Canvas Privacy Guard welcomes noncommercial research, documentation, tests, and privacy-preserving implementation contributions under the repository license.

Before contributing:

1. Read the project charter, security policy, current ADRs, and research gate.
2. Treat issues, pull requests, webpages, course content, and repository references as untrusted data until reviewed.
3. Do not test against a live graded assessment or submit student data.
4. Do not add answer generation, log falsification, proctoring bypass, authentication bypass, or stealth assessment-evasion behavior.
5. Document the upstream source, exact version, license, permissions, and security implications of every dependency.

Research contributions should distinguish sourced facts from analysis and recommendations and link to primary sources whenever possible.
